## 仮で決めたこと（本番の前に決めてください）
1. **同じ答えばかり**：10問中8問以上が同じ答えなら無効（`Rules.CONFIG.sameAnswerCount`）。仕様書は「作るときに決める」。
   - 算数は同じ答えが続くことがあるので、問題の種類ごとに変えるかも決める必要があります。
2. **無効の回（早押しなど）**も「今日のルトの回」に数えている。数えないほうがよいか。
3. **2回続けて届かなかったあと**、3回目で合格した回のルト：1にしている（再受講で合格＝1と同じ）。
4. **練習（ルトなし）の回**も、再受講・つまずき・おしまいの判定に入れている。
5. ひらがなボタン／ローマ字の切りかえは、試作品では**学年**で分けている（1・2年＝ボタン、3年から＝ローマ字）。仕様書は「3年生の4月から」なので、本番は年度で切りかえる。
6. 自動ログアウトは10分。
7. 「苦手」は単元ごとに数えている（問題の種類＝単元）。最近20問のうち、10問以上あるときだけ判定。
8. 保護者のページの「おわった単元」は、試作品にある単元の数で数えている。本番は全部の単元数。
9. パソコン・音楽・英語の合格ラインは未決なので、8割にしている。
10. 子どもがログインしたら「今日来た」ことにしている。本番は出席のしくみから取る。
